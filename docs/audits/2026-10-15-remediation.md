## Newly closed local feature gaps

The Luffy source declarations in `EI-point.zip` were checked against `bots/luffy/src/commands/{cardinfo,cardstats,deck,hand,play,score,cardadmin}.ts` and `bots/luffy/src/lib/game.ts`. The current target now has executable handlers for card instance inspection and collection counts; issue/revoke owner actions; and the five-card house game state and commands. A second approved guild cannot inspect an instance from the first guild. Revoked cards disappear from active inventory/statistics and cannot be listed or transferred. Duplicate delivery of a `/play` interaction returns its stored result rather than advancing the deck a second time.

The migrated game keeps the 52-card round/deck/hand/score/record rules, but does not recreate the archive's casino loot inventory or sell-value estimate. These behaviors need an explicit product decision and a compatible persistent item model before being called parity-complete.
